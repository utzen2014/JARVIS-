# JARVIS-
Yeni yapay zeka asistanınız.
JARVIS için gerekli olanların hepsi klasörün içindeki "oku beni ve requirements txt" dosyalarında yazıyor.
## 🔑 Gemini API Key Kurulumu

JARVIS'in yapay zekâ özelliklerini kullanabilmek için bir **Google Gemini API Key** gerekir.

### 1. Google AI Studio'yu aç

Tarayıcıdan Google AI Studio'ya gir:

https://aistudio.google.com/

Google hesabınla giriş yap.

### 2. API Key oluştur

Google AI Studio'da **Get API key / API anahtarı al** bölümüne gir.

Ardından:

**Create API key / API anahtarı oluştur**

seçeneğine tıkla.

Gerekli adımları tamamladıktan sonra sana özel bir API Key oluşturulur.

API Key yaklaşık olarak şöyle görünür:

```text
AIzaSyXXXXXXXXXXXXXXXXXXXXXXXX
```

> ⚠️ Bu sadece örnektir. Kendi API Key'ini kullanmalısın.

### 3. API Key'i kopyala

Oluşturulan API Key'in yanındaki **Copy / Kopyala** butonuna bas.

**API Key'ini kimseyle paylaşma.**

### 4. JARVIS'i aç

JARVIS'i çalıştır.

Ardından:

**⚙️ Ayarlar → 🔑 API Ayarları**

bölümüne gir.

### 5. API Key'i yapıştır

API Key alanına Google AI Studio'dan kopyaladığın anahtarı yapıştır.

Örneğin:

```text
AIzaSyXXXXXXXXXXXXXXXXXXXXXXXX
```

Ardından:

**Kaydet**

butonuna bas.

### 6. JARVIS'i yeniden başlat

API Key kaydedildikten sonra JARVIS'i kapatıp tekrar aç.

Artık Gemini destekli JARVIS özelliklerini kullanabilirsin. 🤖

### ⚠️ Önemli

API Key'ini:

* GitHub'a yükleme
* README'ye yazma
* Başkalarıyla paylaşma
* Ekran görüntüsünde gösterme

API Key'in başkalarının eline geçerse Google AI Studio üzerinden ilgili anahtarı **silip yeni bir API Key oluşturman** gerekir.
